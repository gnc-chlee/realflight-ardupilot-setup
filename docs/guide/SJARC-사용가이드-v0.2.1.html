화면 예시에 대해

이 가이드의 화면은 RealFlight 9 PC를 기준으로 한 예시입니다. 경로의 사용자 자리에는 실제 Windows 사용자 이름이 나오고, 목록의 기종과 상태는 PC마다 다를 수 있습니다.

기획·교육 적용·검증: 이충현 (세종사이버대학교 드론로봇융합학과 초빙교수)
AI 개발도구를 활용해 만든 개인 제작 교육지원 도구입니다. 대학 · RealFlight · MFE · ArduPilot의 공식 제품이 아니며, 보증이나 인증을 뜻하지 않습니다.

1단계대상 확인

  1. RealFlight 실행 파일 목록에서 사용할 버전을 확인합니다. RF 9 PC라면 "RealFlight 9 / 9.5 / 9.5S"입니다.
    목록이 비어 있으면 실행 파일 직접 선택 → RF 설치 폴더의 RealFlight.exe(또는 RealFlight64.exe)를 고릅니다.
  2. 사용자 문서 폴더가 문서\RealFlight 9(또는 9.5)인지 확인합니다. 없으면 RF를 한 번 실행·종료한 뒤 다시 검색을 누릅니다.
  3. 다음: 모델 준비를 누릅니다.

2단계모델 준비

  1. 설정할 기종을 체크합니다. 보통 4종 모두 둡니다.
  2. 옵션은 그대로 둡니다.
    • 전진 프롭 브레이크 보정: 기본으로 켜 둡니다.
    • 모델·텍스처 경로 보정: Evolution 전용입니다. RF 8/9에서는 회색(사용 안 함)이 정상입니다.
  3. 모델 준비 / 기존 모델 패치를 누르고, 확인 창에서 대상(제품 · 문서 폴더)을 확인한 뒤 확인을 누릅니다.
  4. 결과를 봅니다.
    • 이미 RF에 있는 기종 → 보정 완료 (신호 보정을 바로 마침)
    • 아직 없는 기종 → Import 필요 → 도우미가 자동으로 3단계 화면으로 넘어갑니다.

원본 파일은 도우미와 같은 폴더(USB)에 있으면 그대로 씁니다. 없으면 GitHub에서 약 13 MB를 받습니다. 어느 쪽이든 해시로 검증하고, 바꾸기 전 파일은 모두 문서\RealFlight 9\.SJARC\Backups에 백업합니다.

3단계RealFlight에서 Import

RealFlight 9 / 9.5에서는 Import가 필요한 기종마다 아래를 반복합니다.

  1. RealFlight 열기로 RF를 엽니다.
  2. MFE가 아닌 기본 기체(예: Piper Cub)를 먼저 선택합니다. MFE 기체가 선택된 채로 Import하면 "This battery is in use" 오류가 납니다(4종이 같은 배터리 파일을 씁니다).
  3. Simulation → Import → RealFlight Archive (RFX, G3X)를 누르고 목록의 파일을 고릅니다. 파일은 문서\RealFlight 9\RFX\SJARC에 있습니다(Import 폴더 열기).
  4. 끝에 "경로를 찾을 수 없습니다" 창이 나오면 확인을 누릅니다. 원본 모델에 제작자 PC 경로가 들어 있어 나오는 것으로 문제없습니다.
  5. 모두 가져왔으면 RealFlight를 완전히 종료하고 도우미에서 Import 끝냄 → 다음을 누릅니다.
주의
  • 이미 설치된 기종은 다시 Import하지 마세요. 보정과 복구는 4단계가 합니다.
  • Evolution에서는 My RealFlight → Import → RealFlight Archives입니다.

4단계검사·패치

  1. RF · Mission Planner · SITL이 모두 꺼져 있는지 확인합니다. 오른쪽 위 배지가 RF·MP 꺼짐 · 파일 작업 가능이어야 합니다.
  2. Import 후 검사·패치를 누르고 확인을 누릅니다.
  3. 모든 기종이 보정 완료이면 성공입니다. "확인 필요" 문구가 나오면 그대로 따릅니다(예: 조종기 설정의 Dual Rates and Expo 끄기).
  4. RF를 열고 기체 선택에서 원래 이름을 고른 뒤 FLY를 눌러 오류 없이 뜨는지 봅니다.
    STRIVERminiVTOL · Pioneer · fighterVTOL · HERO2180 (다른 이름으로 저장한 사본은 보정되지 않습니다)

5단계SITL 연결

가장 쉬운 방법: SITL 시작 (flightaxis)
  1. RealFlight를 켜고 기체를 고릅니다.
  2. 도우미 5단계에서 SITL 시작 (flightaxis)을 누릅니다. 항상 flightaxis로, 같은 파라미터 저장소로, Wipe 없이 켭니다.
  3. Mission Planner가 안 켜져 있으면 도우미가 켜 주고, MP가 스스로 연결합니다. 오른쪽 위 단추가 DISCONNECT로 바뀌면 연결된 것이니 다시 누르지 마세요.
  4. RF에서 스페이스바(리셋)를 누르고 "FlightAxis Controller Device has been activated"가 나오는지, 도우미 상태 줄에 SITL flightaxis로 실행 중이 보이는지 확인합니다.
  5. 끌 때는 SITL 종료 (또는 SITL 검은 창 닫기), RealFlight는 마지막에 끕니다.

Mission Planner의 Simulation 탭에서 직접 켜도 됩니다: Simulation → Model = flightaxis → Plane → Stable, Wipe 체크 금지. 처음 한 번은 Config → Planner → Layout = Advanced로 바꿔야 Simulation 탭이 보입니다.

Simulation 탭에서 Model을 flightaxis로 고르지 않으면

SITL이 RF와 따로 돌아서 RF 기체는 넘어지는데 Mission Planner 화면은 그대로입니다(배터리 12.60V 고정). 파라미터 저장소도 달라져서 비행모드가 MANUAL · FBWA만 보입니다. 파라미터가 지워진 것이 아니니, SITL을 닫고 flightaxis로(또는 SITL 시작으로) 다시 켜면 돌아옵니다.

SITL 파라미터 적용

연결된 대상이 DISARM 상태의 SITL인지 확인한 뒤 진행합니다. 처음이라면 Full Parameter List → Save to file로 기존 값을 먼저 저장해 두세요.

  1. Mission Planner CONFIG → Full Parameter List → Load from file로 아래 파일을 고릅니다.
  2. Write Params를 누릅니다.
  3. SITL을 다시 시작합니다(Simulation에서 다시 연결).

첫 확인 (DISARM 상태부터)

  1. DISARM 상태에서 모드 스위치가 바뀌는지, MANUAL에서 조종면 방향이 맞는지 봅니다.
  2. Mission Planner Status 탭에서 스로틀(ch3in)이 최저·최고일 때 약 1000/2000인지 봅니다.
  3. QLOITER(또는 QHOVER) → Arm → 스로틀을 살짝 올려, RF 화면에서 모터 4개가 같이 도는지 봅니다.
  4. 한쪽으로 뒤집히면 즉시 Disarm하고 SERVO11 = 36, SERVO12 = 35인지 확인합니다.

"Q_ASSIST_SPEED is not set"으로 Arm이 거부되면 파라미터 파일을 불러오지 않은 것입니다. 도우미는 Arm이나 이륙을 하지 않으며, 수직비행부터 단계적으로 직접 시험합니다.

연결 문제 해결

SITL 연결 중 RealFlight가 "응답 없음"이 되거나, 처음 설정한 뒤로 연결이 안 될 때 씁니다. 위에서부터 하나씩 해 보세요.

  1. RF가 "응답 없음"이면 창을 닫기 전에 ① 진단 보고서 만들기를 누르고, SITL 검은 창을 휴대폰으로 찍어 둡니다. 진단은 읽기만 하고 아무것도 바꾸지 않습니다.
  2. RF와 MP를 닫고 ② 남은 SITL 창 종료를 누른 뒤, 켜는 순서(RF → 기체 선택 → MP → Simulation)대로 다시 연결합니다.
  3. 계속 멈추면 ③ SITL 저장 설정 초기화를 누릅니다. 파라미터를 넣기 전에 연결부터 확인합니다.
    • 초기화 직후에는 되는데 파라미터를 넣고 재시작한 뒤 멈추면, 파라미터가 원인입니다.
  4. 그래도 멈추면 ④ RealFlight 설정 초기화(최후 수단)를 누릅니다. 조종기 선택·보정과 Physics 설정을 다시 합니다.
  5. 해결되지 않으면 SITL 설정 되돌리기와 RF 설정 되돌리기로 원래대로 돌리고, ①의 zip과 사진을 보내 주세요.

③ · ④와 되돌리기는 RF · MP · SITL이 모두 꺼져 있어야 실행됩니다. 초기화는 파일을 지우지 않고 백업 이름으로 옮기므로 언제든 되돌릴 수 있습니다.

증상원인해결
RF 기체는 넘어지는데 MP 화면은 그대로, 배터리 12.60VMP에서 Model을 flightaxis로 고르지 않음MP·SITL 닫고 도우미 [SITL 시작], 또는 Simulation → Model = flightaxis
껐다 켜니 비행모드가 MANUAL · FBWA만 보임다른 Model로 켜져 다른 파라미터 저장소를 씀파라미터 다시 쓰기 전에 flightaxis로 다시 켜기 (도우미 [SITL 시작] 권장)
SITL 연결 전 RF 기체가 계속 뒤집히고 리셋됨연결 전에는 조종기 채널 값으로 모터가 돎SITL을 연결하면 멈춥니다(정상)
Import 중 "This battery is in use"MFE 기체가 선택된 채 Import기본 기체(예: Piper Cub)를 선택한 뒤 Import
Import 끝에 "경로를 찾을 수 없습니다"원본 모델 속 제작자 PC 경로확인을 누르면 됩니다(무해)
FLY를 누르면 RF 오류 창예전 도우미(v0.1.2/0.1.3)의 경로 보정RF 종료 → 도우미 4단계 다시 실행(자동 복구)
뜨자마자 한쪽으로 뒤집힘모터 3·4 번호 반대SERVO11 = 36, SERVO12 = 35 확인
"Q_ASSIST_SPEED is not set"으로 Arm 거부파라미터 파일을 안 불러옴기종 파일 Load → Write → SITL 재시작
SITL 연결 중 RF "응답 없음"여러 원인"연결 문제 해결" 순서대로
도우미: "RealFlight · Mission Planner · SITL을 먼저 모두 종료하세요"프로그램이 켜져 있음모두 종료 후 다시(응답 없음이면 작업 관리자에서 끝내기)
도우미 목록에 RealFlight가 없음RF를 한 번도 실행하지 않았거나 다른 위치에 설치RF 실행·종료 후 다시 검색, 또는 실행 파일 직접 선택
