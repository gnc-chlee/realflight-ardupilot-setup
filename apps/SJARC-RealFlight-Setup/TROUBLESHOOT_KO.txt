연결 문제 해결 — SITL 연결 중 RealFlight가 '응답 없음'이 되거나, 처음 설정 뒤로 연결이 안 될 때

이 화면의 기능
① 진단 보고서 만들기: 읽기만 하고, 파일과 설정은 바꾸지 않습니다.
   RF·MP가 켜져 있거나 멈춘 상태에서도 누를 수 있습니다. 멈췄을 때 누른 보고서가 원인을 찾는 데 가장 도움이 됩니다.
   보고서(txt)는 메모장으로 열리고, 보낼 파일(zip)은 보고서 폴더에 만들어집니다.
   zip에 넣는 것: 보고서, RF 설정 파일(INI, 사용자 프로필 값은 지움), 조종기 프로필, SITL 버전 정보.
② 남은 SITL 창 종료: Mission Planner가 띄운 SITL(검은 창, ArduPlane)만 닫습니다.
   Mission Planner와 RealFlight는 직접 닫으세요.
③ SITL 저장 설정 초기화: 문서\Mission Planner\sitl\flightaxis 폴더의 이름을 백업 이름으로 바꿉니다(지우지 않음).
   다음 SITL은 기본 파라미터로 시작합니다. 'SITL 설정 되돌리기'를 누르면 원래대로 돌아갑니다.
④ RealFlight 설정 초기화(최후 수단): 선택한 RF의 INI 파일을 .SJARC\IniReset 폴더로 옮깁니다(지우지 않음).
   조종기 선택·보정과 Physics 설정을 다시 해야 합니다. 'RF 설정 되돌리기'를 누르면 원래 INI가 돌아옵니다.

순서 (위에서부터 하나씩)
1. RF가 '응답 없음'이면 창을 닫지 말고 먼저 ①을 누르고, SITL 검은 창을 휴대폰으로 찍어 두세요.
   검은 창에 "Starting controller"가 계속 반복되면, RF가 리셋될 때마다 SITL이 다시 연결하고 있는 것입니다.
2. RF와 MP를 닫고 ②를 누릅니다.
   켜는 순서: RealFlight 실행 → 기체 선택 → 도우미 "5. SITL 연결"의 [SITL 시작]
   (MP Simulation 탭으로 켤 때는 Model = flightaxis → Plane → Stable, Wipe 체크 금지)
   끄는 순서: Mission Planner(SITL)를 먼저 끄고, RealFlight는 마지막에 끕니다.
   RF의 Reset 기능에 지정된 조종기 스위치가 켜져 있지 않은지 확인합니다(① 보고서에 입력 번호가 나옵니다).
   RF 기체가 넘어지는데 Mission Planner 화면이 그대로이고 배터리가 12.60V로 고정이면, SITL이 RF에 붙지 않은 것입니다.
   Simulation에서 Model = flightaxis를 골랐는지 확인하세요(① 보고서에 SITL 명령줄이 나옵니다).
3. 그래도 멈추면 모두 닫고 ③을 누릅니다. 파라미터를 넣기 전에 연결만 먼저 확인합니다.
   · 초기화 직후에도 멈추면: SITL 파라미터 문제가 아닙니다. 4번으로 갑니다.
   · 초기화 직후에는 되는데, 기종 param을 Load → Write하고 SITL을 재시작하면 멈추면: 파라미터가 원인입니다.
     ①을 다시 만들어 보내 주세요.
4. 그래도 멈추면 ④를 누르고 RF를 실행합니다. 조종기를 선택·보정한 뒤 Settings → Physics를 다음처럼 맞춥니다.
   RealFlight Link = Yes / Pause Sim When in Background = No / Pause Sim When in Menu = No / Automatic Reset Delay = 2.0
   RF를 재시작한 뒤 연결을 확인합니다.
5. 그래도 안 되면 'RF 설정 되돌리기'와 'SITL 설정 되돌리기'로 원래대로 돌리고, ①의 zip과 사진을 보내 주세요.

주의
· ③, ④와 되돌리기는 RealFlight · Mission Planner · SITL이 모두 꺼져 있어야 실행됩니다.
· 초기화해도 기체·모델 파일과 조종기 프로필은 바뀌지 않습니다. 자동 ARM·이륙도 하지 않습니다.
· 파라미터를 다시 넣을 때는 문서\RealFlight 9\.SJARC\Parameters의 기종별 파일을 씁니다(5단계 '파라미터 폴더 열기').
  초기화한 SITL에는 두 번 불러옵니다: Load → Write → SITL 재시작 → Refresh Params → 같은 파일 Load → Write.
  한 번만 하면 Q_ 파라미터가 기본값으로 남아 "Q_ASSIST_SPEED is not set"으로 ARM이 거부됩니다.
